# Standards

Taxonic supports standardized classification systems to organize and categorize content consistently.

## Supported Standards

### HECoS

The Higher Education Classification of Subjects (HECoS) provides a structured classification system for academic subjects and higher education content.

### BISAC

The Book Industry Standards and Communications (BISAC) classification system organizes books and publications into standardized subject categories.

## How Classification Works

1. Submit a title and description.
2. Select the required classification standard.
3. Taxonic analyzes the submitted content.
4. Receive relevant classification codes and confidence scores.

## API Integration

You can select the classification standard using the `standard` parameter in your API request.
