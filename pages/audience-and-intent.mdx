# Audience

Taxonic is designed for developers, researchers, data professionals, and organizations that need reliable subject classification.

## Who Can Use Taxonic?

- **Developers:** Integrate automated classification into applications using the Taxonic API.
- **Researchers:** Classify academic content using established classification standards.
- **Data Teams:** Organize and enrich large datasets with standardized subject classifications.
- **Organizations:** Automate content categorization and improve metadata consistency.

## Understanding Audience and Intent

Taxonic analyzes the title and description of submitted content to identify its subject, context, and intended audience.

This helps generate relevant classification suggestions based on the selected classification standard.
