# Pricing

Explore Taxonic pricing and API usage options.

## API Access

Taxonic provides API-based classification capabilities for integrating subject classification into your applications and workflows.

## Usage Considerations

Your API usage may depend on:

- Number of classification requests.
- Volume of records processed.
- Selected classification features.
- API access requirements.

## Getting Started

1. Obtain your Taxonic API credentials.
2. Configure the API key in your application.
3. Send classification requests.
4. Monitor your API usage.
