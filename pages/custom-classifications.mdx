# Custom Classifications

Taxonic provides configurable classification parameters to help tailor classification results to specific requirements.

## Configuration Options

### Code Prefix

Use `code_prefix` to narrow classification results to a particular code prefix.

### Maximum Results

Use `max_results` to control the maximum number of classification suggestions returned.

### Minimum Score

Use `min_score` to filter suggestions based on their confidence score.

## Custom Classification Workflow

1. Select your classification standard.
2. Define the required code prefix, if applicable.
3. Configure the maximum number of results.
4. Set the minimum confidence score.
5. Submit your classification request.

These options help customize classification output for different use cases.
