# Taxonic API Documentation

The official documentation and interactive API playground for **Taxonic**. This website provides developers with API references, integration guidance, and tools to explore and test Taxonic APIs.

🌐 **Website:** https://usetaxonic.com

## Overview

Taxonic provides API services for classification and data processing. This repository contains the documentation website, API reference, and interactive playground designed to make API integration easier for developers.

## Features

- **API Reference:** Interactive API documentation generated from the OpenAPI specification.
- **API Playground:** Test API endpoints directly from the browser.
- **Authentication:** Configure API keys and request headers.
- **Request & Response Viewer:** Inspect API requests, responses, and HTTP status codes.
- **FAQ:** Find answers to common questions and integration-related queries.
- **Custom Landing Page:** Dedicated landing page introducing Taxonic services.
- **Responsive Design:** Optimized documentation experience across desktop and mobile devices.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### 1. Clone the Repository

```bash
git clone <repository-url>
cd taxonic
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

The development server will start. Open the local URL displayed in your terminal.

### 4. Build for Production

```bash
npm run build
```

Use the production build generated by the project for deployment.

## API Documentation

The API reference is generated using the OpenAPI specification located at:

```text
apis/taxonic.yaml
```

The specification is configured in `zudoku.config.tsx`:

```tsx
apis: [
  {
    type: "file",
    input: "./apis/taxonic.yaml",
    path: "/api",
  },
],
```

Developers can explore the available API operations and their request and response schemas through the documentation website.

## API Playground

The interactive playground allows developers to test the Taxonic classification API directly from the documentation website.

**Current endpoint:**

```http
POST /v1/classify
```

**Base URL:**

```text
https://taxonic-api.contactous.com
```

The playground supports:

- API key authentication using `X-Taxonic-API-Key`
- JSON request body configuration
- Custom request headers
- Live API response inspection
- HTTP status and response-time display

## Configuration

The main website configuration is maintained in:

```text
zudoku.config.tsx
```

It controls:

- Website metadata and SEO
- Favicon and application name
- Header and logo configuration
- Custom MDX components
- Navigation structure
- OpenAPI documentation integration
- Canonical URL and sitemap settings
